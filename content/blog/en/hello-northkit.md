Northkit is a Next.js starter you fully own. No vendor lock-in, no hidden SaaS.

## What is inside

- Better Auth with email and optional social login
- Drizzle ORM on SQLite
- Native i18n with RTL support
- Three themes driven by CSS tokens

## Add a post

Drop a Markdown file in `content/blog/<locale>/` with `title`, `description` and `date` in the frontmatter. It shows up in the blog, the sitemap and the RSS feed.
