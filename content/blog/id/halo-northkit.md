Northkit adalah starter Next.js yang sepenuhnya milikmu. Tanpa vendor lock-in.

## Isinya

- Better Auth dengan email dan login sosial opsional
- Drizzle ORM di SQLite
- i18n bawaan dengan dukungan RTL
- Tiga tema berbasis token CSS

## Menambah tulisan

Taruh file Markdown di `content/blog/<locale>/` dengan `title`, `description`, dan `date` di frontmatter. Otomatis muncul di blog, sitemap, dan RSS.
